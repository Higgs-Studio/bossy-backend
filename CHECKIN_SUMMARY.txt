================================================================================
ARCHITECTURE
================================================================================

Cron Job (every 30-60 min)
    ↓
POST /trigger-checkin
    ↓
Query: next_checkin_at <= NOW()
    ↓
For each user:
  - Fetch user context (goals, tasks, status)
  - Generate AI message (personalized, boss type specific)
  - [Fallback to default if AI fails or no context]
  - Send WhatsApp (async background task)
  - Calculate next check-in
  - Update database
    ↓
Return results

  ORDER BY last_checkin_at DESC LIMIT 10;

================================================================================
TROUBLESHOOTING
================================================================================

No check-ins being sent:
  1. Check cron is running: ps aux | grep cron
  2. Test endpoint: curl -X POST http://server/trigger-checkin
  3. Check logs: tail -f /var/log/app.log

User not receiving messages:
  1. Verify phone number format (no + or spaces)
  2. Check Twilio logs
  3. Verify user has opted in (sent message first)

Wrong frequency:
  $ python test_checkin.py --set-boss-type USER_ID execution
